## 1주차
페르소나와 구현해볼 스토리 목록에 대해서 이야기 해보자!

- 페르소나
    - sns를 자주 사용하는 고등학생 김군
    - 소셜네트워크 관심이 있던 김군은 일상 속에 이야기를 공유하고 싶어한다.
- 구현해 볼 스토리 목록
    - 관계 : 서로 팔로우 한 관계를 친구라 정의
    - 게시글 공개 범위:
        - 전체 : 로그인 한 모든 사용자가 읽기 가능
        - 팔로우 : 팔로우 한 유저만 읽기 가능
        - 친구 : 친구인 유저만 읽기 가능
    - 검색 기준
        - 제목을 기준으로 검색을 한다.
    - 프로필 지표
        - 게시글 수, 댓글 수, 좋아요 수
        - 팔로워, 팔로잉
        - 게시글 검색
    - 마이 페이지
        - 게시글 수, 댓글 수, 좋아요 수
        - 팔로워, 팔로잉
        - 게시글 관리, 아이디 변경, 비밀번호 변경
        - 게시글 검색
    - 로그인
        - id는 이메일 형태로 진행, 패스워드는 영문자 + 숫자로 진행
    - 회원가입
        - 중복되지 않는 이메일로 검증, 패스워드는 영문자 + 숫자로 진행(비밀번호 확인도 진행)
        - 닉네임도 중복을 허용하지 않는다.
